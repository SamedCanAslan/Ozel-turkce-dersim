# Özel Türkçe Dersi — Samed Can Aslan

Android / Google Play için hazırlanmış proje.

- Application ID: `com.samedcanaslan.ozelturkcedersi`
- Target SDK: 36
- Compile SDK: 36
- Release AAB: GitHub Actions tarafından üretilir.

## GitHub'da kullanım

1. Bu klasörün **içindeki tüm dosyaları** repository'nin köküne yükleyin. `app/`, `.github/`, `build.gradle`, `settings.gradle` aynı seviyede görünmelidir.
2. GitHub → Actions → **Build Android AAB** → **Run workflow**.
3. Başarılı çalışmadan sonra workflow'un **Artifacts** bölümünden `samed-can-aslan-aab` dosyasını indirin.

## Site

Uygulama, `https://ozelturkcedersim.netlify.app/` sitesini WebView içinde açar. Harici bağlantılar cihazın uygun uygulamasında açılır.
